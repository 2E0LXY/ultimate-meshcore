Each tile takes 128 KB on the card (the T-Deck draws them without decoding). A town at zoom 10 to 14 is usually a few hundred tiles; a county at 10 to 15 a few thousand.

3. Where the tiles come from

Use {z}, {x} and {y} (and {s} for a server letter if the provider uses one). The server must allow web pages to read its tiles (CORS); most commercial tile services do. OpenStreetMap's own tile servers are run by volunteers and their tile usage policy does not allow downloading areas for offline use, so this tool will not use them (or other sources whose terms forbid it). The map above uses them only for viewing.

5. Put it on the card

    
    
      
  1. Use a microSD card formatted FAT32 (cards up to 32 GB come that way).
    2. 
      
  2. Unzip the file onto the top level of the card. You should then have a maps folder at the top, like this:
        
    SD card
    └─ maps
       ├─ 10
       │  └─ 507
       │     └─ 330.bin
       └─ 11 …
    
        Not maps/maps/… and not umc-maps-…/maps/…: if your unzip tool makes an extra folder, move maps up to the top.
    3. 
      
  3. Put the card in the T-Deck and restart it (or open Map). Info → Maps shows SD maps, zoom 10-14 when it has found them.
    4. 
      
  4. To add another area later, unzip it onto the same card: the folders merge and nothing is lost.
