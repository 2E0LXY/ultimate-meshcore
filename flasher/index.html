Ultimate MeshCore Flasher

Install the latest Ultimate MeshCore build on your device over USB, straight from your browser.

Browser not supported

USB flashing needs Chrome or Edge on a desktop or laptop (Windows, macOS, Linux or ChromeOS). Phones and Firefox/Safari can't access USB serial ports.

1. Choose your device

Loading builds…

2. Connect and install

  1. Plug the device into this computer with a data USB cable.
  2. Press Install and pick the device's serial port (CP210x / USB JTAG / USB Serial).
  3. When asked “Erase device?”:
    • No — update and keep the node's identity, name, radio and all settings.
    • Yes — fresh install. A new identity is created and the setup hotspot starts.
Use Chrome or Edge on a computer. This page must be opened over https. Download full image Download update .bin

Device not detected? Hold the PRG/BOOT button, tap RST, release PRG, then try again. On Windows you may need the CP210x driver.

3. After installing

  1. A new or erased device starts an open WiFi hotspot called UMC-Setup-XXXX. Join it and the setup page opens (or browse to http://192.168.4.1).
  2. Updated devices keep their settings: open http://umc-<name>.local/ or the IP shown on the display.
  3. Later updates can be done over WiFi from the device's Firmware page using the update .bin.
Back up anything important first. Flashing the wrong board's firmware can stop a device booting until you re-flash the correct one.
